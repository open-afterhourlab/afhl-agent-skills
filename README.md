# afhl-agent-skills

Opinionated list of agent skills by After Hour Lab to support opinionated set of workflows.

## Workflows

The skills in this repository support various workflows for various purposes.

### Build Product

This is an opinionated workflow to build product for product and engineering teams.

| Workflow | Description | 
| -------- | ----------- |
| [Problem Exploration](./docs/workflows/build-product/problem-exploration/) | Understanding the problems, establishing concepts and business requirements that solves the problem |
| Technical Design | Designing the technical solution that solves the problem |
| [Coding](./docs/workflows/build-product/coding/) | TDD centered SDLC |
